# Sango Hiring Tracker

Read-only view of the hiring tracker for Pak Pepy and Pak Aji.

- **Edit** happens in Bu Pam's Claude tracker page.
- `data.enc.json` is the tracker data, encrypted with a password; `index.html` asks for the password and shows it.
- Published with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
